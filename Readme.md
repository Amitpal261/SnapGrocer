## 🚀 About The Project

SnapGrocer is a **modern grocery delivery web application** inspired by real-world platforms like Instamart and Blinkit.

It focuses on **performance, scalability, and user experience**, delivering lightning-fast search, seamless navigation, and visually engaging UI.

👉 Designed as a **portfolio-grade project** to demonstrate frontend engineering skills, UI/UX design, and performance optimization.

---

## 🔥 Key Features

* 🔍 **Real-Time Smart Search**
  Instant product filtering with optimized rendering

* 🧭 **Category-Based Navigation**
  Structured browsing for better user experience

* 🛍️ **Dynamic Product Listings**
  Clean, reusable component architecture

* ⭐ **Ratings & Pricing UI**
  Real-world inspired product data

* 🖼️ **Lazy Loading Images**
  Improved performance & reduced load time

* ✨ **Skeleton Loading (Shimmer UI)**
  Better perceived performance

* 📱 **Fully Responsive Design**
  Mobile-first, works across all devices

* ⚡ **Smooth UI Animations**
  Enhanced interaction experience
