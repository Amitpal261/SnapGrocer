# 🛒 QuickBasket

QuickBasket is a modern grocery delivery web application inspired by platforms like Swiggy Instamart and Blinkit. It provides a seamless shopping experience with fast search, category filtering, and smooth UI interactions.

---

## 🚀 Features

* 🔍 **Smart Search** – Instantly filter products
* 🧭 **Category Filtering** – Browse by categories
* 🛍️ **Product Listing** – Clean and responsive product cards
* ⭐ **Ratings & Pricing** – Realistic product data
* 🖼️ **Lazy Loading Images** – Optimized performance
* ✨ **Shimmer UI (Skeleton Loading)** – Better user experience
* 📱 **Fully Responsive Design**
* ⚡ **Fast UI with smooth transitions**

---

## 🧑‍🍳 Product Details Page

* Detailed product/recipe view
* Ingredients and instructions
* Interactive UI with highlights
* Smooth image loading with placeholders

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **Routing:** React Router
* **State Management:** React Hooks (useState, useEffect, useContext)
* **API:** Dummy JSON API (for simulation)

## ⚙️ Installation

1. Clone the repository:

```
git clone https://github.com/your-username/quickbasket.git
```

2. Navigate to project:

```
cd quickbasket
```

3. Install dependencies:

```
npm install
```

4. Run the app:

```
npm run dev
```
